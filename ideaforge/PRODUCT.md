# PRODUCT.md — IdeaForge AI

## One-Line Definition
AI agent SaaS that converts vague ideas into fully built, 
GitHub-pushed products via structured clarification, blueprint 
generation, and semi-automatic Claude Code execution.

## Target Users
- Non-technical founders (idea → product, no coding needed)
- Developers (scaffolding + architecture fast)
- Students / Beginners (guided learning + working output)

## Core Problem
Users can't convert vague ideas into structured, buildable 
products without knowing prompting, architecture, or system design.

## How It Works (6 Stages)
1. IDEA CAPTURE     → multi-modal input → structured idea JSON
2. BLUEPRINT        → architecture + stack + schema + API spec
3. PROMPT GENERATION→ master + task + debug prompt set
4. EXECUTION        → Claude Code builds product task by task
5. GITHUB PUSH      → approved code pushed to user's repo
6. DEPLOY           → auto-deploy to Vercel + Railway

## Key Differentiators
- BYOK (bring your own API key) — zero API cost to platform
- Version-verified stack (live PyPI/npm registry checks)
- Selective file injection (60-70% token reduction)
- Agent owns error fixing — Claude Code only executes
- Semi-automatic — user approves every stage output
- Multi-modal input (text, voice, image, file)

## Business Model
- Free tier: 2 projects/month, Claude API only
- Pro tier: unlimited projects, all integrations, deploy
- BYOK: user pays Anthropic/OpenAI directly
- Platform charges subscription only
